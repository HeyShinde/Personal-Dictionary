# Personal Dictionary Website

This website is built with **Astro 7** and configured for hosting on **Cloudflare Pages**.

## Tech Stack & Architecture
- Framework: [Astro 7](https://astro.build/) (`astro@^7.4.4`)
- Adapter: Cloudflare Pages compatible (Static by default, optional `@astrojs/cloudflare`)
- Styling: Modern CSS with scoped Astro components, CSS variables, glassmorphism, responsive grid & flexbox
- Interactive features: Zero-runtime client islands / micro-scripts using vanilla JavaScript & Web Speech API

## Development & Build
- `npm run dev` - Start Astro development server
- `npm run build` - Build production static bundle to `dist/`
- `npm run preview` - Preview the built static site locally
- `npm run check` - Type-check Astro and TypeScript code
